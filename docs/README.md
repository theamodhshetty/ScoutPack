# ScoutPack Documentation

ScoutPack is a local repository index and context compiler for AI coding agents. Start with one task, inspect the packet, then hand it to your agent.

## Start Here

1. [Install ScoutPack](installation.md) through Cargo source installation.
2. [Generate your first packet](getting-started.md) without a manual indexing step.
3. [Choose a client workflow](ai-agent-workflows.md) or [configure MCP](mcp.md).
